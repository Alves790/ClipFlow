# 🌊 ClipFlow

**ClipFlow** est un gestionnaire de presse-papier multiplateforme léger et minimaliste. 
Il tourne discrètement en arrière-plan et garde en mémoire l'historique de vos textes copiés pour vous éviter de perdre des informations importantes.

## 🎯 Objectif du projet
Ce projet est développé dans un but d'apprentissage et d'ingénierie logicielle. L'objectif est de comprendre :
- L'interaction avec le système d'exploitation (OS).
- La gestion des processus en arrière-plan.
- La persistance des données (fichiers JSON).
- La création d'une interface utilisateur fluide.

## 🛠️ Technologies utilisées
- **Langage :** Python 3
- **Bibliothèques principales :** `pyperclip` (gestion du presse-papier)
